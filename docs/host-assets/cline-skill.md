# Cline Skill Template

Use this as a Cline-native skill or custom workflow note:

```markdown
Name: GrokSearch Research Companion

Use the `grok-search` MCP server whenever external web context is needed.

- Prefer `plan_* -> web_search`
- Use `get_sources` when source verification matters
- Use `web_fetch` and `web_map` for focused retrieval
- Treat `deep_research_*` as advanced non-interactive jobs
- Keep interactive deep research in the CLI with `grok-search-research`

Do not widen every lookup into a deep research job.
```
